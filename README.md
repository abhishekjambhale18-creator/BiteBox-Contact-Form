> Added a complete **Customer Registration & Order Form** to the BiteBox Contact page using HTML form elements.

---

### 📌 Project Overview
This lab focuses on creating an interactive **HTML Form** on the Contact page.  
Users can now enter personal details, select food items, choose payment methods, add extras, and submit their order.

---

### ✨ What Was Added in Contact Page
- Full Customer Registration & Order Form
- Text, Email, Password, Phone, Number, and Date inputs
- Dropdown (`select`) for food items
- Radio buttons for Payment Method (Cash / Card / UPI)
- Checkboxes for Extras (Extra Cheese, Cold Drink, Dessert)
- Textarea for Delivery Address
- Submit and Reset buttons

---

### 📄 Pages Included

| Page    | File           | Description                                      |

| Home    | `index.html`   | Semantic structured home page                    |
| Menu    | `menu.html`    | Menu with table, images & lists                  |
| About   | `about.html`   | About Us page                                    |
| Contact | `contact.html` | Contact page with full registration & order form |

---

### 🛠️ Skills Demonstrated
- HTML Forms (`form`, `input`, `label`)
- Input types: `text`, `email`, `password`, `tel`, `number`, `date`
- Dropdown using `select` and `option`
- Radio buttons and Checkboxes
- Textarea
- Submit & Reset buttons
- Multi-page navigation

---

### 🚀 How to Run
1. Open the repository
2. Open `index.html` in any web browser
3. Go to the **Contact** page to see the form
